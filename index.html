基板AI診断（AIを用いた基板トラブルシューティング）

RTミドルウェアコンテスト 応募作品

1. 作品概要

「基板AI診断」は、動かない電子回路基板の写真を Google の Gemini API に送信し、不具合の原因候補や次に確認すべき手順を日本語で提示するRTミドルウェアシステムです。

  • 視覚的な原因特定：診断結果は「まとめ」と「詳細」で表示し、異常が疑われる箇所は基板写真の上に赤い枠と番号で分かりやすく示します。
  • 多角的な手がかりの入力：故障基板の写真だけでなく、正常な基板の写真・回路図・使用部品の写真や症状メモを添えることで診断精度を高められます。
  • 診断履歴と一致率の記録：診断ごとに結果と画像を自動保存し、後から「当たり・外れ」を入力してAI診断の一致率を集計・確認できます。
  • ワンクリック起動：専用ランチャー（Launcher.py）により、ネームサーバーと3つのRTCの起動・ポート接続・アクティブ化・停止を自動で行えます。

2. 使用したRTミドルウェアのバージョン

  • OpenRTM-aist 2.1.0（Windows 64bit版 / Python）

4. 開発したRTC・再利用したコンポーネント

本システムは、機能を役割ごとに分離した3つのRTコンポーネント（RTC）と、それらを一括制御するランチャーで構成されています。

Camera_RTC（入力） ──[TimedString]──▶ AIDiagnosis_RTC（AI診断） ──[TimedString]──▶ Display_RTC（結果表示）

新規開発したRTC

コンポーネント名 役割・機能 ポート仕様
Camera_RTC.py 基板写真の撮影（Webカメラ）または既存画像の選択、正常基板・回路図・部品画像や症状メモの入力、診断依頼の送信を行うGUIコンポーネント。 OutPort: request_out
(TimedString / JSON形式)
AIDiagnosis_RTC.py 受け取った画像パスと説明文をもとに Gemini API で異常解析を行い、怪しい箇所に赤枠・番号を描画した画像の作成とログ記録を行うコンポーネント。 InPort: request_in
OutPort: result_out
(TimedString / JSON形式)
Display_RTC.py 診断の経過と結果（「まとめ」「詳細」切替）、赤枠付き写真の別ウィンドウ表示、診断の当たり外れ評価の記録・一致率集計を行うGUIコンポーネント。 InPort: result_in
(TimedString / JSON形式)

起動・制御プログラム

  • Launcher.py / Start_BoardAI.bat：環境チェック、ネームサーバー（omniNames）および3つのRTCの自動起動・ポート接続・アクティブ化・一括停止を行うランチャー。

再利用したコンポーネント

  • なし（すべてのRTCおよびランチャーをPythonで新規開発しています）

6. 動作方法・デモ動画

動作方法（クイックスタート）

  1. 事前準備：Python 3、OpenRTM-aist 2.1.0、および必要ライブラリ（pip install opencv-python google-genai pillow）をインストールし、Google AI Studio で Gemini APIキーを取得します。
  2. 起動：リポジトリのファイル一式を展開したフォルダ（例：C:\board_ai）内の Start_BoardAI.bat をダブルクリックします。
  3. システム開始：ランチャー画面で「Gemini APIキー」を入力して「開始」を押すと、3つのRTCが自動で起動・接続・アクティブ化されます。
  4. 診断実行：Camera_RTC で基板の写真を撮影または選択し、「診断へ送る」を押すと、10〜60秒ほどで Display_RTC に診断結果と赤枠付きの箇所表示が現れます（詳細はユーザーマニュアル参照）。
